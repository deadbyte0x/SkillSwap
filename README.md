# SkillSwap

## Платформа обмена навыками

SkillSwap — веб-приложение для поиска и обмена навыками между пользователями. Пользователи могут просматривать навыки, находить подходящих участников, фильтровать предложения и взаимодействовать с контентом платформы.

Проект разработан в рамках командной работы. В процессе разработки использовались современные подходы к организации frontend-приложений: компонентная архитектура, TypeScript, Redux Toolkit и Feature-Sliced Design.

## 🚀 Технологический стек

* **React**
* **TypeScript**
* **Redux Toolkit**
* **React Router**
* **Vite**
* **CSS**
* **Feature-Sliced Design (FSD)**
* **ESLint**
* **Prettier**
* **GitHub Actions**
* **Jest / тестирование компонентов**

## ✨ Функциональность

* просмотр каталога навыков;
* фильтрация пользователей по навыкам и параметрам;
* работа с пользовательскими карточками;
* система лайков;
* защищенные маршруты;
* валидация пользовательских данных;
* переиспользуемые UI-компоненты;
* адаптивный интерфейс.

* Создал компонент выпадающего списка навыков.
* Реализовал защищенные маршруты для страниц приложения.
* Добавил обработку лайков и счетчик количества лайков.

## 🏗 Архитектура проекта

Проект построен с использованием Feature-Sliced Design:

```
src/
├── app/          # провайдеры приложения, глобальные настройки
├── entities/     # бизнес-сущности
├── features/     # пользовательские функции
├── pages/        # страницы приложения
├── shared/       # переиспользуемые компоненты и утилиты
└── widgets/      # составные блоки интерфейса
```

## ⚙️ Установка и запуск

Клонировать репозиторий:

```bash
git clone https://github.com/PM-YandexPracticum/SkillSwap_51_4.git
```

Установить зависимости:

```bash
npm install
```

Запустить проект:

```bash
npm run dev
```

Приложение будет доступно:

```
http://localhost:5173
```
